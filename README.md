# AI Programming Fundamentals

Welcome to **AI Programming Fundamentals** at Seoul Cyber University for the Fall semester of 2026.

This course introduces the fundamentals of Python programming through hands-on practice. You will learn to write, run, and apply basic Python programs while building a foundation for further study in Python Data Analysis and Big Data Analysis and AI Modeling.

The course uses executable Jupyter Notebook files as the primary lecture notes and programming materials. These notebooks can be opened and run in Google Colab.

PDF versions of the weekly lecture notes are available under Lesson Plan Archive with each week’s lesson plan. For convenient access to both the lecture materials used in class and the Jupyter Notebook lecture notes, please use the link below:
