# AI Programming Fundamentals

Welcome to **AI Programming Fundamentals** at Seoul Cyber University(SCU) for the Fall semester of 2026.

This course introduces the fundamentals of Python programming through hands-on practice. You will learn to write, run, and apply basic Python programs while building a foundation for further study in Python Data Analysis and Big Data Analysis and AI Modeling.

In this course, we use executable Jupyter Notebook files and lecture slides as the primary lecture notes. You can open and run the notebook files in Google Colab.

In addition to the SCU portal site, course materials for AI Programming Fundamentals can also be found at:<br>
