BASIC CONDITIONS

The Basic Structure of an if Statement

▶Code cell
age = 20
if age >= 18:
    print('You are an adult.')
print('Program finished.')
Output
You are an adult.
Program finished.

Run only when true

An if statement runs an indented block only when its condition is true.

After that decision, Python continues with the next statement.

condition → True or False
BASIC CONDITIONS

When the Condition Is False

▶Code cell
temperature = 28
if temperature > 30:
    print('It is very hot.')
print("That's today's weather update.")
Output
That's today's weather update.

The block is skipped

When the condition is false, Python does not execute the indented block.

The program continues with the first line after the block.

False condition → skip block
BASIC CONDITIONS

The if-else Statement

▶Code cell
score = 75
if score >= 60:
    print('You passed.')
    print('Congratulations!')
else:
    print('You did not pass.')
    print('Try again next time.')
Output
You passed.
Congratulations!

Exactly one path runs

Use else when the program must choose between two paths.

Here, the score is high enough, so Python runs the passing branch.

if branch or else branch

No usable value yet

None is used when a variable has no meaningful value yet.

pass is different. It is a placeholder for an empty block.

Choose one branch

elif adds another condition between if and else.

Python runs the first true branch and skips the rest.

first true branch runs
COMPOUND CONDITIONS

Nested Conditional Statements

▶Code cell
age = 20
has_license = True
if age >= 18:
    if has_license:
        print('You can drive.')
    else:
        print('You need a driver license.')
else:
    print('You are too young to drive.')
Output
You can drive.

A condition inside another condition

A nested conditional places one conditional statement inside another.

Use nesting only when it makes the decision rule clearer.

outer decision → inner decision
COMPOUND CONDITIONS

Handling More Complex Conditions

▶Code cell
temperature = 25
is_raining = False
if temperature > 30:
    print('Be careful in the sun.')
elif is_raining:
    print('Take an umbrella.')
else:
    print('The weather is nice.')
Output
The weather is nice.

Several possible paths

Multiple branches can represent a practical decision rule.

Keep each condition focused so the flow remains easy to read.

if → elif → else
LOGICAL OPERATORS

Logical Operators

and

Both conditions must be true.

T and TTrue
T and FFalse

or

At least one condition must be true.

T or FTrue
F or FFalse

not

The truth value is reversed.

not TrueFalse
not FalseTrue

Logical operators combine simple comparisons into more realistic conditions.

LOGICAL OPERATORS

Logical Operators in Code

▶Code cell
age = 25
has_license = True
if age >= 18 and has_license:
    print('You can drive.')
else:
    print('You cannot drive.')
Output
You can drive.

Combine two requirements

The and operator requires both conditions to be true.

Use or when one condition is enough, and not to reverse a Boolean value.

and · or · not
LOGICAL OPERATORS

Chained Comparisons

if 0 < x < 10:

x is greater than 0 and less than 10.

CONDITIONAL EXPRESSIONS

Using Conditional Expressions

Conditional expressions are useful for simple value selection.

abs_x = x if x >= 0 else -x5
parity = 'even' if num % 2 == 0 else 'odd''odd'

Use this form when the condition and both outcomes fit naturally on one line.

CONDITIONAL EXPRESSIONS

Advantages and Disadvantages

Good for simple choices

It can make a short value assignment concise when both outcomes are simple values.

Not for complex logic

When the condition has many steps, a regular conditional statement is usually easier to read.

Clarity matters more than making the code shorter.

CONDITIONAL EXPRESSIONS

Branch Order and Clarity

Python checks branches from top to bottom and stops at the first true condition.

Top-down check

The first true branch is selected, so branch order affects the path.

Clear ranges

For grading rules, place ranges in a clear and consistent order.

Avoid hidden overlap

Overlapping conditions can make later branches unreachable.

CONDITIONAL EXPRESSIONS

Minimizing Nested Conditional Statements

▶Code cell
x = 10
y = 5
if x > 0 and y > 0:
    print('Both are positive.')
elif x > 0:
    print('Only x is positive.')
else:
    print('x is not positive.')
Output
Both are positive.

Prefer a readable structure

Deep nesting can make code hard to follow.

When conditions are simple, combining them may make the decision rule easier to see.

combine simple conditions
DATA & AI

Data and AI Applications

▶Code cell
raw_value = 75
max_value = 100
normalized = raw_value / max_value if max_value != 0 else 0
normalized
Output
0.75

Safe value selection

A conditional expression can select a fallback value when a calculation would not be valid.

Here, the expression avoids division by zero.

use 0 when max_value is 0
