VARIABLES

Variables, Assignment, and = vs. ==

▶Code cell
score = 80        # = binds a name
score = score + 5 # reassignment
print(score)
print(score == 85) # == compares
Output
85
True

A variable is a name

Assignment binds a name to an object; reassigning simply moves the name. One = assigns, two == compare — mixing them up is a classic exam trap.

= assigns · == compares
TYPE CONVERSION

Type Conversion — int() Truncates

▶Code cell
print(int('42') + 8)
print(int(3.9))
print(float('3.5'))
print(str(10) + '!')
Output
50

3.5
10!

Convert on purpose

Text from input arrives as str — convert before arithmetic. And remember: int(3.9) is 3, because int() cuts off the decimal part. It does not round.

int() truncates, never rounds

LISTS

Lists — Index, Slice, Change

▶Code cell
scores = [85, 90, 78, 92]
print(scores[0], scores[-1])
print(scores[1:3])
scores[2] = 80
print(sum(scores) / len(scores))
Output
85 92
[90, 78]
86.75

The workhorse container

Lists are ordered and mutable: read by index, slice a range, replace an element in place. len(), sum(), max() combine into the classic average pattern.

average = sum / len
LISTS

List Methods to Know

.append(x)add at the end
.insert(i, x)add at position i
.remove(x)delete first x
.pop()remove & return last
.index(x)where is x?
.count(x)how many x?
nums.sort() vs. sorted(nums)in place · new list

.sort() changes the list and returns None; sorted() leaves it alone and returns a new sorted list. Also: .remove() on a missing value raises an error — check with in first.

TUPLES

Tuples — Immutable, and the Comma Matters

▶Code cell
point = (3, 5)
x, y = point      # unpacking
print(x, y)
single = (5,)     # one-element tuple
print(type(single))
point[0] = 9
Output
3 5
<class 'tuple'>
TypeError: 'tuple' object does not
support item assignment

A fixed record

Tuples index and slice like lists but cannot be changed — assignment into a tuple raises TypeError. And (5) is just the number 5: the comma, not the parentheses, makes a tuple.

(5,) is a tuple · (5) is not
DICTIONARIES

Dictionaries — Look Up by Key

▶Code cell
person = {'name': 'Mina', 'age': 21}
print(person['name'])
person['city'] = 'Seoul'   # add
del person['age']          # delete
print('name' in person)
Output
Mina
True

Key → value

Read and write through keys, not positions. Keys must be immutable (strings, numbers, tuples — never lists) and each key is unique. Note that in checks the keys, not the values.

in checks keys
SETS

Sets — No Duplicates, No Order

▶Code cell
nums = {1, 2, 2, 3, 3, 3}
print(nums)
a = {1, 2, 3}
b = {3, 4}
print(a | b, a & b, a - b)
Output
{1, 2, 3}
{1, 2, 3, 4} {3} {1, 2}

Membership machine

Duplicates disappear the moment a set is created — that alone answers many exam questions. Union |, intersection &, and difference - compare whole collections at once.

len({1,2,2,3}) == 3
DATA STRUCTURES

Which One Do I Use?

Let the job pick the structure:

list

an ordered collection that changes

Scores to append, rows to sort, items in sequence.

tuple

a fixed record

A coordinate, an RGB color — values that belong together and never change.

dict

lookup by name

A profile, a translator, counts per word — anything shaped key → value.

set

uniqueness & membership

Remove duplicates, test “have we seen this?”, compare groups.

CONDITIONALS

if / elif / else — Order Matters

▶Code cell
score = 75
if score >= 90:
    print('A')
elif score >= 70:
    print('B')
else:
    print('C')
Output
B

One branch runs

Python checks conditions top to bottom and runs the first true branch only. Put the narrower condition first — if score >= 70 came before >= 90, a 95 would print B.

first True branch wins
CONDITIONALS

What Counts as True?

bool(0)False
bool(3.5)True
bool('')False
bool('0')True
bool([])False
bool([0])True
bool(None)False

Zero, empty things, and None are falsy — everything else is truthy. The string '0' is True because it is not empty, and [0] is True because the list holds one element.

CONDITIONALS

Logical Operators, Chained Comparisons, in

▶Code cell
age = 25
print(18 <= age < 65)
print(age > 20 and age % 2 == 0)
print('py' in 'python',
      3 in [1, 2, 3])
Output
True
False
True True

Combine conditions

and needs both sides true; or needs one; not flips. A chained comparison 18 <= age < 65 reads like math, and in tests membership in strings, lists, and dictionary keys.

18 <= age < 65
CONDITIONALS

Conditional Expressions — if-else in One Line

▶Code cell
score = 85
result = 'pass' if score >= 60 else 'fail'
print(result)
Output
pass

Value, not statement

A conditional expression picks one of two values, so it fits inside an assignment. Use it for simple choices; once branches multiply, a full if-elif-else stays clearer.

A if condition else B
LOOPS

while — Repeat Until Something Changes

▶Code cell
count = 0
while count < 5:
    if count == 3:
        break
    print(count)
    count += 1
Output
0
1
2

Condition-driven

The condition is checked before each pass, so the loop body must move it toward False — or run forever. break exits the loop at once; continue skips to the next pass.

update the loop variable
LOOPS

for and range() — Visit Each Item

▶Code cell
total = 0
for x in [10, 20, 30]:
    total += x
print(total)
for i in range(1, 10, 4):
    print(i)
Output
60
1
5
9

Iterable-driven

A for loop visits every item of an iterable — list, string, or range(). Remember range(start, end, step) stops before end, exactly like slicing. The accumulator pattern total += x appears everywhere.

range end is excluded
LOOPS

Loop Tools to Recognize

Three forms you should be able to read on sight:

comprehension

[x*2 for x in nums]

Build a new list from a loop in one line — optionally with a filter: if x > 0.

enumerate()

for i, v in enumerate(names)

Loop with the index and the value together.

zip()

for n, s in zip(names, scores)

Walk two sequences in parallel, pair by pair.
