FUNCTIONS

What Is a Function?

function()
A function is a reusable block of code.

It has a name and performs one clear task when we call it.

Reuse

Write the task once and call it many times.

Organize

Divide a program into smaller, named parts.

Read clearly

A good function name explains the purpose of the code.

FUNCTIONS

Why Use Functions?

A function is useful when the same task appears more than once.

BEFORE

Repeated code

print('Hello!')
print('Hello!')
print('Hello!')
The same line is copied several times.
AFTER

Define once, call many times

def say_hello():
    print('Hello!')

say_hello()
say_hello()
say_hello()
The repeated task is stored in one named block.

Parameters and Arguments

▶Parameter and argument
def greet(name):  # name is a parameter
    print('Hello,', name + '!')

greet('Alice')  # 'Alice' is an argument
Output
Hello, Alice!

Parameter vs. argument

A parameter receives a value. An argument is the value we pass when calling the function.

namereceives'Alice'
RETURN VALUES

Using Arguments in Function Calls

▶Same function, different inputs
def add_numbers(a, b):
    result = a + b
    print(a, '+', b, '=', result)

add_numbers(3, 5)
add_numbers(2, 7)
Output
3 + 5 = 8
2 + 7 = 9

Change the arguments

The function body stays the same. The arguments change the result.

add_numbers(a, b)

ADVANCED FUNCTIONS

Local and Global Variables

▶Local and global variables
global_var = 10

def print_variables():
    local_var = 20
    print('Global variable:', global_var)
    print('Local variable:', local_var)

print_variables()
Output
Global variable: 10
Local variable: 20

Scope controls visibility

A global variable exists outside functions. A local variable exists only inside its function.

where a name can be used
ADVANCED FUNCTIONS

Using a Global Variable Inside a Function

▶Modify a global variable
count = 0

def increment():
    global count
    count += 1
    print('Current count:', count)

increment()
increment()
increment()
Output
Current count: 1
Current count: 2
Current count: 3

Use global carefully

global lets a function change a global variable. Use it only when the shared state is needed.

global count

ADVANCED FUNCTIONS

Flexible Arguments: *args and **kwargs

▶Flexible input
def print_args(*args, **kwargs):
    print(args, kwargs)
    print(type(args), type(kwargs))

    for arg in args:
        print(arg)

    for key, value in kwargs.items():
        print(key, value)

print_args(1, 2, 3, name='Alice', age=30)
Output
(1, 2, 3) {'name': 'Alice', 'age': 30}
<class 'tuple'> <class 'dict'>
1
2
3
name Alice
age 30

Collect extra inputs

*args receives an arbitrary number of positional arguments.
**kwargs receives an arbitrary number of keyword arguments.

*args becomes a tuple.
**kwargs becomes a dictionary.

Simple Data Transformation with map()

▶map()
temperatures_celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(celsius):
    return (celsius * 9 / 5) + 32

temperatures_fahrenheit = list(map(to_fahrenheit, temperatures_celsius))
temperatures_fahrenheit
Output
[32.0, 50.0, 68.0, 86.0, 104.0]

Transform each value

map() applies one function to every item in a sequence.

transform data
