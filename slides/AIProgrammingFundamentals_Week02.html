Strings as Non-Scalar Objects

A sequence of characters

Letters, digits, spaces, and special characters can all appear inside a string.

Case-sensitive

Non-scalar

The sequence inside a string can be accessed, so a string is a non-scalar object.

Because a string has an internal structure,
we can access and work with individual characters.

VARIABLES & ASSIGNMENT

Naming Variables

Use meaningful names that describe the data.

Variable names may contain letters, digits, and underscores, but they cannot begin with a digit.

Python variable names are case-sensitive.

Use snake_case for ordinary variable names in this course.

Examples: model_accuracy = 0.95 and dataset_size = 10000.

TYPE CONVERSION

Explicit Type Conversion

int()

Converts a value to an integer.

float()

Converts a value to a floating-point number.

str()

Converts a value to its text form.

bool()

Converts a value to True or False.

Type conversion changes a value from one data type to another.
Python provides int(), float(), str(), and bool() for explicit conversion.

TYPE CONVERSION
