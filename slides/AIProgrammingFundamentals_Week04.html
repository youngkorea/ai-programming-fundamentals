Adding and Deleting Pairs

Dictionaries are mutable, so we can change their contents after creation.

Adding a new key:value pair

person['job'] = 'Engineer'

OUTPUT

Deleting a key:value pair

DICTIONARIES

Characteristics of Dictionary Keys

Valid keys

  • Strings
  • Numbers
  • Tuples of immutable values

Invalid keys

  • Lists
  • Dictionaries
  • Other mutable objects

Mutable objects such as lists cannot be used as dictionary keys because keys must be hashable.

DICTIONARIES

Invalid Dictionary Key

▶Code cell
invalid_dict = {[1, 2]: 'list key'}
Error
TypeError: unhashable type: 'list'

A list cannot be a key

A list can change after it is created, so Python cannot safely use it as a dictionary key.

Use an immutable key such as a string or tuple instead.

use immutable keys

DICTIONARIES

Characteristics of Dictionaries

Insertion order

Modern Python preserves the order in which key:value pairs are inserted.

Mutable

Dictionary contents can be modified after creation.

Unique keys

Each key must be unique. A later value replaces an earlier value for the same key.

Dictionary equality depends on the key:value pairs, not on the order in which those pairs were inserted.

DICTIONARIES

Order and Unique Keys in Code

These examples show how dictionaries behave with order and repeated keys.

Assigning again updates the value

What Is a Set?

unique
values
A set keeps only one copy of each element.

A set is an unordered collection of unique and immutable objects.

SETS

Creating Sets

Use curly braces {} or set() to create a set. Use set() for an empty set.

An empty set

empty_set = set()
empty_set
OUTPUT
set()

A set with curly braces

fruits1 = {'apple', 'banana', 'orange'}
fruits1
OUTPUT
{'apple', 'banana', 'orange'}

A set from a list

fruits2 = set(['apple', 'banana', 'orange'])
fruits1 == fruits2
OUTPUT
True

When the same value appears more than once, the set keeps only one copy.

This is why sets are useful for duplicate removal.

SETS

Set Operations in Python

Sets support common mathematical operations that organize relationships among collections of values.

|

Combines all distinct elements that appear in either set.
Useful for merging collections while preserving uniqueness.

&

Selects only the elements shared by both sets.
Useful for identifying overlap, agreement, or common membership.

-

Returns elements in the first set but not in the second.
Useful for isolating exclusive items or detecting change.

SETS

SETS

Characteristics of Sets

Unordered

Sets do not support positional indexing, and display order is not the main point.

Mutable

Elements can be added or removed after a set is created.

Unique

Every element appears only once, even if the input has duplicates.

Sets are useful when presence or uniqueness matters more than order.

SETS

Set Characteristics in Code

Same elements, different written order

OUTPUT
True

Duplicate numbers are kept once

set3
OUTPUT

Set length counts unique elements

len(set3)
OUTPUT

SETS

Restrictions on Set Elements

▶Code cell
set4 = {1, 'a', [2, 3]}
Error
TypeError: unhashable type: 'list'

Set elements must be hashable

Like dictionary keys, set elements should use immutable values.

Strings, numbers, and tuples can be elements, but lists cannot.

immutable elements only
