Strings as Sequences

"text"
A string is an ordered sequence of characters.

Python stores each character in order, so we can access text by position.

Text value

A string represents text such as a word, sentence, label, or code.

Ordered positions

Each character has a position. The first position uses index 0.

Index and slice

Indexing reads one character. Slicing reads a range of characters.

Length and Immutability

Strings are immutable. We can create a new string, but we cannot change one character in place.

▶Code
text = 'Hello'
print(len(text))
text[0] = 'h'
Output
5
TypeError: 'str' object does not support item assignment

Remember

Immutable means the object cannot be changed after it is created.

text.replace('H', 'h')New string: 'hello'

Simple Sentiment Example

Simple text processing can support basic rule-based analysis.

▶Code
review = 'This model is fast and useful'
positive_words = ['fast', 'useful', 'accurate']

FORMATTING

The % Operator

The older % operator inserts values into placeholders.

▶Code
name = 'Model A'
accuracy = 92.7
message = 'Model: %s, Accuracy: %.1f%%' % (name, accuracy)
print(message)
Output
Model: Model A, Accuracy: 92.7%

Placeholders

%s is for text. %.1f formats a number with one decimal place.

FORMATTING

The str.format() Method

str.format() uses placeholders and passes values through the method call.

▶Code
name = 'Model B'
accuracy = 88.234
message = 'Model: {}, Accuracy: {:.2f}%'.format(name, accuracy)
print(message)
Output
Model: Model B, Accuracy: 88.23%

Structure

{} marks a position. {:.2f} controls numeric display.

FORMATTING

f-Strings

An f-string puts variables and expressions directly inside a string.

▶Code
name = 'Model C'
accuracy = 95.126
message = f'Model: {name}, Accuracy: {accuracy:.2f}%'
print(message)
Output
Model: Model C, Accuracy: 95.13%

Recommended style

f-strings are readable and common in modern Python code.

FORMATTING

Formatting Numbers

Formatting helps control decimal places, percentages, and aligned output.

▶Code
value = 0.9274
print(f'{value:.2f}')
print(f'{value:.1%}')
print(f'{value:>10.2f}')
Output
0.93
92.7%

REGULAR EXPRESSIONS

What Is a Regular Expression?

A regular expression is a pattern used to find or match text.

▶Code
import re
text = 'Hello World'
match = re.search(r'World', text)
print(match is not None)
Output
True

Module

Python uses the re module for regular expressions.

REGULAR EXPRESSIONS

Basic Pattern Matching

re.search() looks through a string and returns a match object when the pattern is found.

▶Code
import re
text = 'Course code: APF10'
match = re.search(r'APF10', text)
print(match.group())
Output
APF10

Raw string

The prefix r helps write regex patterns clearly.

REGULAR EXPRESSIONS

Character Sets

A character set matches one character from a group of possible characters.

▶Code
import re
text = 'cat cot cut'
matches = re.findall(r'c[ao]t', text)
print(matches)
Output
['cat', 'cot']

Pattern

[ao] means “a or o” in that position.

REGULAR EXPRESSIONS

Shorthand and Repetition

Shorthand patterns and repetition marks help describe common text structures.

▶Code
import re
text = 'ID: 2026, Code: A101'
print(re.findall(r'\d+', text))
print(re.findall(r'[A-Z]\d{3}', text))
Output
['2026', '101']
['A101']
\d\w\s{n}
REGULAR EXPRESSIONS

Main Functions in re

Three common functions are enough for many beginner-level text processing tasks.

▶Code
import re
text = 'Call 010-1234-5678'
masked = re.sub(r'\d', '*', text)
print(masked)
Output
Call ***-****-****

re.findall()return all matches

DATA & AI

Extracting Dates from Text

Regular expressions can extract structured patterns from unstructured text.

▶Code
import re
text = 'Start: March 1, 2000. End: September 1, 2100.'
pattern = r'[A-Z][a-z]+ \d{1,2}, \d{4}'
matches = re.findall(pattern, text)
print(matches)
Output
['March 1, 2000', 'September 1, 2100']

Data workflow

Pattern extraction is useful before cleaning, counting, or analyzing text data.
