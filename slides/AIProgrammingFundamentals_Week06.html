WHILE LOOPS

Basic Structure of a while Loop

A while loop repeatedly runs an indented block while its condition is True.

condition

while condition:

Python checks the condition before each repetition.

block

indented code

Only the indented block belongs to the loop.

update

change the condition

The loop usually changes a value so it can eventually stop.

WHILE LOOPS

Counting with a while Loop

▶Code cell
count = 0
while count < 5:
    print(count)
    count += 1 # count = count + 1
print('Loop finished.')
Output
0
1
2
3
4
Loop finished.

Update the loop variable

The variable count changes inside the loop. This prevents the loop from running forever.

count += 1
WHILE LOOPS

Using break to Exit a Loop

▶Code cell
while True:
    response = input('Would you like to continue? (y/n): ')
    if response == 'n':
        break
print('Program finished.')
Output
Would you like to continue? (y/n): y
Would you like to continue? (y/n): n
Program finished.

Stop from inside the loop

while True creates a loop that would continue indefinitely. break exits when the stopping condition is met.

break

Nested while Loops

▶Code cell
i = 2
while i <= 3:
    j = 1
    while j <= 3:
        print(i, 'x', j, '=', i * j)
        j += 1
    i += 1
    print()
Output
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6

3 x 1 = 3
3 x 2 = 6
3 x 3 = 9

Loop inside a loop

The inner loop completes its repetitions for each single repetition of the outer loop.

nested repetition

FOR LOOPS

Basic Structure of a for Loop

A for loop takes one item at a time from an iterable object.

iterable

data to visit

A list, tuple, dictionary, set, string, or range can provide items.

variable

current item

The loop variable refers to the item currently being processed.

block

repeated action

The indented block runs once for each item.

FOR LOOPS

Looping Over Iterable Data

A for loop visits each element of an iterable object one by one.

▶List
fruits = ['apple', 'banana', 'cherry']
for fruit in fruits:
    print(fruit)
Output
apple
banana
cherry
▶String
for char in 'Python':
    print(char)
Output
P
y
t
h
o
n

Using range() with a for Loop

range() generates a number sequence that a for loop can use.

range(stop)0 up to stop
range(start, stop)start up to stop
range(start, stop, step)increase or decrease by step

FOR LOOPS

The else Clause with a for Loop

▶Code cell
numbers = [1, 3, 5, 7, 9]
search_number = 4
for num in numbers:
    if num == search_number:
        print(search_number, 'was found!')
        break
else:
    print(search_number, 'was not found.')
Output
4 was not found.

Search pattern

The else block runs only if the loop finishes without finding the item and without using break.

for ... else

LOOP TOOLS

List Comprehensions

A list comprehension builds a new list from an existing sequence in one concise line.

▶Basic form
squares = [x ** 2 for x in range(10)]
squares
Output
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
▶With condition
even_squares = [x ** 2 for x in range(10) if x % 2 == 0]
even_squares
Output
[0, 4, 16, 36, 64]
LOOP TOOLS

The enumerate() Function

▶Code cell
fruits = ['apple', 'banana', 'cherry']
for index, fruit in enumerate(fruits, start=1):
    print(index, fruit)
Output
1 apple
2 banana
3 cherry

Index and value together

enumerate() is useful when both the position and the item value are needed during iteration.

index, value

The zip() Function

▶Code cell
names = ['Alice', 'Bob', 'Charlie']
ages = [25, 30, 35]
for name, age in zip(names, ages):
    print(name, age)
Output
Alice 25
Bob 30
Charlie 35

Parallel iteration

zip() lets a loop take related items from multiple iterables at the same time.

name + age
LOOP TOOLS

Combining Loops and Conditions

▶Code cell
odd = []
even = []
for num in range(1, 11):
    if num % 2 == 0:
        even.append(num)
    else:
        odd.append(num)
print('Odd:', odd)
print('Even:', even)
Output
Odd: [1, 3, 5, 7, 9]
Even: [2, 4, 6, 8, 10]

Classify values

A loop can repeat the same decision rule over many values. This pattern appears in filtering and preprocessing tasks.

loop + if-else
LOOP CHOICE

Choosing Between while and for Loops

while loop

Use it when repetition depends on a condition, and the number of repetitions is not known in advance.

repeat until something changes

for loop

Use it when the iterable or the number of repetitions is already clear.

visit each item
