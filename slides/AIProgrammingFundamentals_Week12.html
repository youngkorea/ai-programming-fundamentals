FILE READING AND WRITING

The Concept of File I/O

File input/output (I/O) lets a program save data and read it back.

01

Open

Select a file and a mode with open().

02

Read or write

Move information between Python and the file.

03

Close

Release the file after the operation.

KEY IDEAUse with open(...) to close a file automatically.
FILE READING AND WRITING

Opening and Closing Files

A file mode determines how Python accesses an existing or new file.

01

r — Read

Open an existing file. The file must exist.

02

w — Write

Create a file or overwrite its previous contents.

03

a — Append

Add text at the end without replacing existing contents.

KEY IDEAw overwrites; a preserves existing content.
FILE READING AND WRITING

The with Statement

The with statement defines a file operation and closes the file on exit.

01

Automatic closing

The file closes at the end of the block.

02

Clear scope

Indentation shows where the file is used.

03

Safer handling

Closing still occurs when the block raises an error.

KEY IDEAPrefer with open(...) as file: for ordinary file access.
FILE READING AND WRITING

Writing Text with write()

▶ Code cell
with open('notes.txt', 'w', encoding='utf-8') as file:
    file.write('Hello, Python!\n')
    file.write('File I/O is useful.')

print('Saved notes.txt')
Output
Saved notes.txt

Write two lines to notes.txt using write().

w mode creates or overwrites the file.
\n starts a new line.
FILE READING AND WRITING

Reading Files

Choose a reading method based on how much text you need.

01

read()

Get all remaining file contents as one string.

02

readline()

Get the next line as a string.

03

readlines()

Get a list containing the remaining lines.

KEY IDEAReading a file does not modify its contents.
FILE READING AND WRITING

Read an Entire Text File

▶ Code cell
with open('notes.txt', 'r', encoding='utf-8') as file:
    content = file.read()

print(content)
Output
Hello, Python!
File I/O is useful.

Read the text saved in notes.txt.

Run the preceding write example first.
read() returns one string, including the line break.
FILE READING AND WRITING

Read a File Line by Line

▶ Code cell
with open('notes.txt', 'r', encoding='utf-8') as file:
    for line in file:
        print(line.rstrip('\n'))
Output
Hello, Python!
File I/O is useful.

Read one line at a time without a manual while loop.

A file object supports iteration directly.
rstrip() removes the line-ending character before print().

CSV AND JSON

Working with CSV Files

CSV (Comma-Separated Values) stores tabular data as rows of values.

01

Rows

Each line represents one record.

02

Columns

Commas separate fields within a row.

03

Python support

The built-in csv module reads and writes records.

CSV AND JSON

Write a CSV File

▶ Code cell
import csv

rows = [['Name', 'Age'], ['Alice', 25], ['Bob', 30]]
with open('people.csv', 'w', newline='', encoding='utf-8') as file:
    writer = csv.writer(file)
    writer.writerows(rows)

print('Saved people.csv')
Output
Saved people.csv

Write a small table of records using csv.writer().

Each inner list becomes one CSV row.
newline="" avoids extra blank rows on some systems.
CSV AND JSON

Read a CSV File

▶ Code cell
import csv

with open('people.csv', 'r', newline='', encoding='utf-8') as file:
    for row in csv.reader(file):
        print(row)
Output
['Name', 'Age']
['Alice', '25']
['Bob', '30']

Read back the CSV rows as lists of strings.

Run the CSV writing example first.
CSV values are read as strings by default.
CSV AND JSON

Working with JSON Files

JSON (JavaScript Object Notation) represents structured data.

01

Objects

JSON objects map names to values, like Python dictionaries.

02

Arrays

JSON arrays resemble Python lists.

03

Python support

The built-in json module handles conversion and file storage.

CSV AND JSON

Save Data to JSON

▶ Code cell
import json

person = {'name': 'Alice', 'age': 25}
with open('person.json', 'w', encoding='utf-8') as file:
    json.dump(person, file)

print('Saved person.json')
Output
Saved person.json

Store a dictionary as a JSON file.

json.dump() writes a Python value to a file.
JSON stores names and values as structured data.
CSV AND JSON

Load JSON from a File

▶ Code cell
import json

with open('person.json', 'r', encoding='utf-8') as file:
    loaded = json.load(file)

print(loaded)
Output
{'name': 'Alice', 'age': 25}

Load JSON data into a Python dictionary.

Run the JSON saving example first.
json.load() reads from a file; json.loads() reads a string.

SEOUL CYBER UNIVERSITY
EXCEPTION HANDLING

The Concept of Exceptions

An exception interrupts the normal sequence of instructions.

01

What happens?

An operation may fail while the program runs.

02

What appears?

Python reports an exception type and traceback.

03

What can we do?

Use try and except to handle an expected failure.

KEY IDEAHandling an exception helps the program respond rather than simply stop.
EXCEPTION HANDLING

An Unhandled Exception

▶ Code cell
result = 10 / 0
print('This line is not reached.')
Output
Traceback (most recent call last):
  File "<cell>", line 1, in <module>
ZeroDivisionError: division by zero

An uncaught division-by-zero error interrupts execution.

ZeroDivisionError identifies the problem.
The second statement is not executed.
EXCEPTION HANDLING

Handle ZeroDivisionError

▶ Code cell
try:
    result = 10 / 0
except ZeroDivisionError:
    print('Cannot divide by zero.')

print('The program continues.')
Output
Cannot divide by zero.
The program continues.

Handle the expected error with an except block.

try contains the operation that may fail.
except supplies a response, then execution continues.
EXCEPTION HANDLING

Handling Different Exceptions

▶ Code cell
try:
    number = int('abc')
    print(10 / number)
except ValueError:
    print('Invalid number.')
except ZeroDivisionError:
    print('Cannot divide by zero.')
Output
Invalid number.

Different exceptions call for different responses.

Replace abc with 0 to trigger ZeroDivisionError.
Catch specific error types rather than hiding all errors.
EXCEPTION HANDLING

The finally Clause

▶ Code cell
try:
    print('Start processing')
finally:
    print('Cleanup complete')
Output
Start processing
Cleanup complete

The finally block runs when the try block exits.

Use it for cleanup or an end-of-task message.
For file objects, with already handles closing.
