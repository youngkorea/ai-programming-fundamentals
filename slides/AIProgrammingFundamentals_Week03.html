Lists

What a list is, how its elements are reached by index and by slice, and how a list changes.

AI Programming Fundamentals
LISTS

What Is a List?

Ordered

Elements keep the position they were given, so each one can be reached by its index.

Several values in one object

Related data stays together instead of living in separate variables.

Mutable

The contents can be changed after the list has been created.

A list is Python's basic way of holding several related values in a single object.

LISTS

List Slicing

Slicing extracts a portion of a list using [start:stop:step], and always produces a new list.

startWhere the slice beginsincluded
stopWhere the slice endsexcluded
stepHow elements are selected from the range1 by default

Any of the three may be left out: numbers[:3] starts at the beginning, and numbers[3:] runs to the end.

The len() function returns the number of elements in a list.

It counts elements, so a list of four words has a length of four, not a length measured in characters.

Lists Are Mutable

▶Code cell

numbers[2] = 30  # Modify the third element

Output
[1, 2, 30, 4, 5]

The list itself changes

Assigning through an index replaces the element in the original list.

No new list is created, and no copy is made.

BEFORE[1, 2, 3, 4, 5]
AFTER[1, 2, 30, 4, 5]

The in operator tests whether a value is present in a list.

The result is a Boolean value, so it fits anywhere a condition is expected.

in → True or False
LIST METHODS

List Methods

append()Adds an element to the end of the list.
insert()Inserts an element at a given position.
remove()Removes the first element with a given value.
pop()Removes and returns the element at a given index.
index()Returns the index of the first matching element.
count()Returns how many times a value appears.
sort()Sorts the elements in place.
reverse()Reverses the elements in place.

Each method is called on the list itself with a dot, and most of them change the original list rather than returning a new one.

Understanding
Tuples

An ordered collection that works like a list, but one that cannot be changed after it is created.

AI Programming Fundamentals
TUPLES

What Is a Tuple?

Ordered

Elements keep their positions, so indexing and slicing work exactly as they do for lists.

Immutable

Once created, elements cannot be replaced, added, or removed.

Written with parentheses

Values are separated by commas, usually inside ( ).

Reach for a tuple when the values belong together and are meant to stay fixed for as long as the program runs.

TUPLES

Tuples Are Immutable

▶Code cell
coordinates = (10, 20, 30)

coordinates[0] = 100
Error
TypeError: 'tuple' object does not support item assignment

No index assignment

A tuple cannot be modified after it is created: no append(), no sort(), no index assignment.

Different values mean building a new tuple.

immutable = fixed for its whole life
TUPLES

Tuple Packing

▶Code cell

print(person)

Commas make the tuple

Packing combines several values into one tuple.

The commas do the work; the parentheses are optional, but usually clearer.

a, b, c → one tuple

One name for each element

The number of names must match the number of elements.

three elements → three names

LISTS VS. TUPLES

Choosing Between Them

Choose a list

The collection will grow, shrink, or have its values replaced while the program runs.

readingslabelspredictions

Choose a tuple

The values belong together and are not supposed to change once they have been set.

(x, y)(year, month, day)(min, max, mean)

Choosing a tuple is a way of stating an intention: these values are meant to stay as they are.

DATA & AI

Tuples in Data Analysis and AI

A tuple is a natural fit whenever a value is made of a fixed number of parts.

A point as (x, y) coordinates

point = (3, 4)
x, y = point
distance = (x ** 2 + y ** 2) ** 0.5
distance
OUTPUT
5.0

A date as three fixed parts

date = (2030, 3, 1)
year, month, day = date
'Date: ' + str(year) + '-' + str(month) + '-' + str(day)
OUTPUT
'Date: 2030-3-1'
DATA & AI

Putting the Concepts Together

▶Code cell
data = (1, 2, 3, 4, 5)

min_val = min(data)
max_val = max(data)
avg_val = sum(data) / len(data)

result = (min_val, max_val, avg_val)
print(result)
Output
(1, 5, 3.0)

A fixed summary of fixed data

data is a tuple, so the values cannot drift
min(), max(), and sum() read it without changing it
The three results are packed back into one tuple
result is a summary that cannot be modified by accident
