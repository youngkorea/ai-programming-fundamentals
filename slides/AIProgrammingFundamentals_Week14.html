FUNCTIONS

Define, Call, Return

▶Code cell
def get_average(scores):
    total = sum(scores)
    return total / len(scores)

avg = get_average([80, 90, 100])
print(avg)
Output
90.0

return hands the value back

def names a reusable block; calling it runs the block with the given argument. return sends the result back to the caller — print() only displays. A function with no return gives back None.

no return → None

f(2, 3)positional — by order

Defaults fill in missing arguments; an argument you pass always wins. And x, y = divide(7, 2) unpacks a multi-value return — the same tuple unpacking from Week Three.

FUNCTIONS

Scope — Local vs. Global

▶Code cell
x = 10

def change():
    x = 99   # a NEW local x

change()
print(x)
Output
10

Assignment makes it local

A name assigned inside a function is local — it lives only during the call and shadows the outside name. So the global x never changes here. Reading a global is fine; rebinding it needs global, which we avoid in this course.

inner x ≠ outer x
FUNCTIONS

Lambda, map(), and filter()

▶Code cell
nums = [1, 2, 3, 4]
doubled = list(map(lambda x: x * 2, nums))
evens = list(filter(lambda x: x % 2 == 0, nums))
print(doubled)
print(evens)
Output
[2, 4, 6, 8]
[2, 4]

A function in one line

A lambda is a small nameless function — one expression, returned automatically. map() applies it to every item; filter() keeps the items where it is True. Wrap both in list() to see the result.

map transforms · filter selects

STRINGS

String Methods to Know

' AI '.strip()'AI'
s.replace('a', 'o')swap text
'a,b'.split(',')['a', 'b']
'-'.join(['a', 'b'])'a-b'
s.upper() / s.lower()change case
s.startswith('AI')True / False

Strings are immutable — every method returns a new string and leaves the original alone. split() makes a list; join() glues one back together — note the separator comes first.

FORMATTING

f-Strings

▶Code cell
name = 'Mina'
score = 91.567
acc = 0.9567
print(f'{name} scored {score:.1f}')
print(f'accuracy: {acc:.2%}')
Output
Mina scored 91.6
accuracy: 95.67%

Values inside the text

An f before the quote lets braces hold live expressions. After the colon comes the format: .1f — one decimal place; .2% — a percentage with two decimals. This is the formatting style we use from here on.

{value:.2f}
REGEX

Regex Building Blocks

\da digit
\wletter, digit, or _
\swhitespace
.any one character
+one or more
*zero or more
[abc] · ^start · end$one of a set · anchors

Write patterns as raw strings — r'\d+' — so the backslashes reach the re module untouched. \d+ reads: one or more digits in a row.

REGEX

The re Functions

▶Code cell
import re
text = 'Exam: 2026-12-15, Room 301'
print(re.findall(r'\d+', text))
print(bool(re.search(r'Room \d+', text)))
Output
['2026', '12', '15', '301']
True

findall vs. search

re.findall() returns every match as a list of strings. re.search() finds the first match anywhere — or None if there is none, which is why it works as a condition.

findall → list · search → first

MODULES

Three Import Patterns

▶Code cell
import math
print(math.sqrt(16))

from random import randint
# randint(1, 6) — no prefix needed

import numpy as np   # alias
Output
4.0

How the name arrives

import math brings the module — you write math.sqrt. from math import sqrt brings the name directly. And as np gives a short alias — the standard style for the data libraries.

module.name vs name

FILES

File I/O with with

▶Code cell
with open('scores.txt', 'w') as f:
    f.write('80\n90\n')

with open('scores.txt') as f:
    for line in f:
        print(line.strip())
Output
80
90

with closes the file

The with statement opens a file and closes it automatically, even if an error occurs. Mode 'w' overwrites, 'a' appends, and no mode means read. Each line keeps its newline — hence strip().

'w' writes · 'a' appends
FILES

CSV and JSON

Two file formats carry most of the data you will meet:

csv

Rows and columns

A plain-text table — one line per row, commas between values. Read and write with the csv module.

json

Nested structures

Dictionaries and lists saved as text. json.dump() writes, json.load() reads — and the data comes back as dicts and lists.

choosing

Which one?

Table-shaped data → CSV. Nested, record-shaped data → JSON. Both are just text files underneath.

EXCEPTIONS

try / except / finally

▶Code cell
try:
    print(10 / 0)
except ZeroDivisionError:
    print('cannot divide by zero')
finally:
    print('done')
Output
cannot divide by zero
done

Fail without crashing

An error inside try jumps to the matching except — the program keeps running. finally runs always, error or not. Catch the specific error you expect, not everything.

finally always runs

NUMPY

NumPy — Element-wise Math

▶Code cell
import numpy as np
a = np.array([1, 2, 3])
print(a * 2)
print(a.mean())
b = np.array([[1, 2], [3, 4]])
print(b.shape)
Output
[2 4 6]
2.0
(2, 2)

No loop needed

Array arithmetic applies to every element at once — that is why there is no for loop. .mean(), .max(), .sum() summarize, and .shape gives (rows, columns).

a * 2 → every element
PANDAS

pandas — Select and Filter

▶Code cell
import pandas as pd
df = pd.DataFrame({'name': ['Mina', 'Juno'],
                   'score': [91, 78]})
print(df['score'].mean())
print(df[df['score'] >= 80])
Output
84.5
   name  score
0  Mina     91

Columns by name, rows by condition

A DataFrame is a table. df['score'] selects a column by name; df[df['score'] >= 80] keeps the rows where the condition is True — the same Boolean logic from Week Five, applied to a whole table.

df[df['score'] >= 80]
VISUALIZATION

One Plotting Pattern

Every chart in Week Thirteen followed the same three steps:

draw

plt.plot() / plt.bar()

Line plots show change over a sequence; bar plots compare categories.

label

title · xlabel · ylabel

A chart without labels cannot be read — name the axes and the chart.

show

plt.show()

Display the figure. Seaborn builds on this same pattern with nicer statistical defaults.
